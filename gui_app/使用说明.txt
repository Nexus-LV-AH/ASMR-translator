音声字幕工房 · 使用说明（普通用户）
=====================================

双击图标即可启动，不需要安装 Python、不需要打开终端、不需要编辑配置文件。

一、第一次启动
1. 把整个文件夹解压到你自己的文档/桌面（不要只把图标拖出来；也不要放进
   “应用程序/Program Files”这种需要管理员权限的目录）。
2. 双击：
   - macOS：音声字幕工房.app
   - Windows：ASMR-Translator.exe
   - Linux：ASMR-Translator
3. 第一次会先打开“安装运行环境”页面：
   - 约 2–4GB，10–30 分钟（取决于网络）；
   - 保持页面打开；国内网络可以勾选 PyPI 镜像；
   - 安装完成后自动打开主界面，以后双击图标即可。
4. 如果系统拦截：
   - macOS：“无法验证开发者” → 右键图标 → 打开 → 打开（只需第一次）；
   - Windows：“Windows 已保护你的电脑” → 更多信息 → 仍要运行；
   - Linux：文件管理器里允许“作为程序执行”。

二、配置翻译方式（第一次进入主界面时）
主界面 → 右上角「设置」：
  A. 推荐：云端大模型 API
     - 选 DeepSeek 官方，填 API Key，点「测试连接」，保存；
     - Key 只保存在本机 .env；只发送字幕文本，音频不会上传；
     - 按量计费，具体以服务商为准。
  B. 本地模型（高级）
     - 点「选择模型文件」，在系统窗口里选 .gguf；
     - 应用会自动识别模型名称、参数量、量化、大小；
     - 可以改显示名称（会写进 LRC 的 [by:]）；保存；
     - 本地模型需要 llama.cpp 的 llama-server；没有就改用云端 API。
  C. 只提取字幕：可以先不配置翻译模型。

三、运行
1. 把“作品文件夹”拖进左上角拖拽区（推荐），或点「选择文件」；
   文件夹里可以有 mp3/wav/flac 等音频和封面图。
2. 作品名会自动识别，可以手动改。
3. 选择任务：
   - 完整运行：提取日文 + 台本精修 + 翻译 → 中文 LRC → 归档作品包；
   - 只提取字幕：音频 → 日文字幕；
   - 制作翻译：已有 .srt / .lrc / .txt 字幕 → 中文 LRC。
4. 点「开始任务」，看进度/日志；可以取消。
5. 结果：
   - output/<作品>/：作品包（字幕、音频、台本）；
   - LRC成品库/<作品>/：中文 LRC 收集目录；
   - 页面上的「打开作品包 / 打开 LRC 成品库」可直接打开。

四、台本（可选）
有官方台本时，把 .txt 台本拖进“台本”区域（按轨道号命名，例如 01.txt），
任务会自动做台本精修；没有台本也能正常跑。

五、退出与数据
- 页面右上角「退出」：关闭界面服务；
- 直接关窗口：服务会保留，双击图标可再次打开；空闲后会自行退出；
- 音频/字幕/作品包都在你解压的文件夹里，不会上传（云端模式只发字幕文本）；
- 升级：下载新版本解压，把旧文件夹里的 input/output/LRC成品库/.models、
  以及 .env、config.local.yaml 复制到新文件夹即可（.venv 会重新安装）。

六、常见问题
- 安装失败/很慢：检查网络/代理，换 PyPI 镜像重试；确认文件夹可写；
- 提示“请把文件夹移到文稿/桌面”：当前目录只读或被系统限制；
- 模型/API 不可用：设置页会显示原因；本地模型需要 llama-server；
- 杀毒软件拦截：未签名应用可能误报，可加入信任；有条件时使用签名版本；
- 长任务中途掉线：任务在本地继续；重新打开页面即可；也可取消后重跑（缓存会复用）；
- 更多文档：README.md、docs/用户指南.md；问题请带日志到项目 issue 反馈。

音频只在本机处理；云端模式只把字幕文本发给你配置的 API。

# 维护者指南（图形界面 / 启动器 / 发布）

## 1. 用户路径 vs 开发路径

- **普通用户**：下载 Release zip → 解压 → 双击 `.app`/`.exe`/可执行启动器 →
  首次安装页 → GUI。不需要 Python、终端、YAML。
- **开发者**：`python3 gui_app/gui.py`（macOS/Linux），或
  `python3 gui_app/launcher/launcher.py --no-open` 调试启动器。CLI 用法完全保留。

## 2. 模块

| 文件 | 作用 |
|---|---|
| `gui_app/gguf_meta.py` | 只读 GGUF 头部：名称/架构/参数量/量化/上下文/聊天模板/分片；显示名 humanize |
| `gui_app/gui_models.py` | 合并 config.yaml + config.local.yaml；模型视图；本地模型增删/default；`.env`/`config.local` 写入；API 测试/保存/清除 |
| `gui_app/gui_fs.py` | 路径解析、作品名/文件名清洗（按 Windows 规则）、上传暂存、落盘、结果扫描、ZIP/预览 |
| `gui_app/gui_jobs.py` | 三阶段命令、子进程、日志、进度解析、取消、last_job |
| `gui_app/gui_platform.py` | 所有 OS 差异：venv 路径、原生选择框、打开文件夹、杀进程树、app 模式浏览器、防休眠、原生错误框 |
| `gui_app/gui_server.py` | 本地 HTTP：页面/静态、token/Host、state、上传、任务、模型、API、预览/下载、退出 |
| `gui_app/webui/` | 主界面 + 设置页（原生 JS/CSS，无构建） |
| `gui.py` | 开发入口：优先转入 `.venv` |
| `gui_app/launcher/` | PyInstaller 小壳：找根目录、复用已运行实例、安装页、启动 GUI |
| `gui_app/launcher/setup_env.py` | 用内置 Python + uv 创建 `.venv` 并安装 requirements |
| `gui_app/launcher/setup_server.py` | 首次安装页服务（只绑定 127.0.0.1，token） |
| `gui_app/tools/build_release.py` | 组装便携发布目录 + zip；PyInstaller 构建启动器；复制内置 Python/uv |
| `gui_app/tests/` | stdlib unittest，三平台 CI |

## 3. 数据流

```
浏览器拖拽 → XHR 上传 → 中间文件/图形界面/上传暂存/{audio,subtitle,promptbook}
开始 → 移动到 input/<作品> 或 中间文件/日文字幕/<作品> 或 promptbook/<作品>
extract_ja.py → 中间文件/日文字幕/<作品>/*.ja.txt
refine_script.py --work <作品> → .ja.refined.txt
translate.py <日文字幕/<作品>> → 中间文件/中文字幕 + LRC → 归档 output/<作品>
                                  → LRC成品库/<作品>
```

- GUI **不调用** `subtitle.py all`：它按作品分两/三段执行，翻译只针对本次作品。
- 子进程用 `sys.executable`（.venv Python）；`child_env()` 统一 UTF-8/HF 缓存；
  `start_new_session`（POSIX）/`CREATE_NEW_PROCESS_GROUP`（Windows）；
  取消用 `killpg` / `taskkill /T`。
- 进度解析失败时显示不确定进度，不伪造百分比。

## 4. 设置写入

- 本地模型 → `config.local.yaml`：
  ```yaml
  translation:
    registry:
      local-<slug>:
        path: /abs/model.gguf
        by_tag: Sakura 14B Qwen3 v1.5 · Q6_K
        note: 本地模型｜15B｜Q6_K｜11.29GB
        vram_gb: 11.29
  ```
- 云端 API → `config.local.yaml`（base_url/model/api_key_env/by_tag）+ `.env`（Key）。
- **绝不修改 tracked 的 config.yaml**；写前保留其他键；格式损坏先备份。
- Key：`.env` 0600；不返回前端、不写日志；保存/清除时同步更新服务进程环境，
  避免 `load_dotenv` 的 `setdefault` 残留旧值。

## 5. 模型自动识别

- GGUF 只读头部 metadata（默认 64MB 预算；tokenizer 大数组只跳过，不加载权重）：
  `general.name` / `general.architecture` / `general.size_label` / `general.file_type`
  / `<arch>.context_length` / `tokenizer.chat_template` / `split.count`。
- `file_type` 映射：18=Q6_K，30=IQ4_XS，15=Q4_K_M 等；文件名量化兜底
  （`q6k`、`iq4xs`、`Q4_K_M`）；参数从 `size_label` 或文件名（14B/7B/1.5B）。
- 显示名优先级：用户 `by_tag` > 自动识别（general.name + 量化）；可编辑；
  LRC `[by:]` 使用它。
- 分片模型自动用第 1 片，缺片警告；识别缓存 `runtime/model_meta.json`（路径+大小+mtime）。
- 非 Sakura/GalTransl、缺聊天模板、识别不完整都会给出警告，但不阻止保存。

## 6. HTTP API（仅 127.0.0.1 + token）

| 方法/路径 | 说明 |
|---|---|
| `GET /?token=` | 主页面 |
| `GET /static/*` | CSS/JS/图标 |
| `GET /api/state?since=` | 设置/模型/暂存/任务/日志增量 |
| `GET /api/settings` / `/api/health` | 设置 / 启动器健康检查 |
| `POST /api/upload?kind&relpath&work_hint` | 原始 body 流式写暂存 |
| `POST /api/start` | 校验/搬移/启动任务 |
| `POST /api/cancel` / `/api/clear` | 取消 / 清空暂存 |
| `POST /api/models/pick` | 系统原生选择框 |
| `POST /api/models/inspect` | GGUF 识别（目录返回候选） |
| `POST /api/models/add` / `remove` / `default` | 本地模型管理 |
| `POST /api/api/test` / `save` / `clear` | 云端 API 设置 |
| `GET /api/preview` / `/api/download` | 预览文本 / LRC ZIP |
| `POST /api/reveal` / `/api/shutdown` | 打开文件夹 / 退出 |

- Host 只允许 `127.0.0.1/localhost:<port>`；POST 校验 Origin；无 CORS；
  CSP/nosniff/no-referrer；路径白名单 + `resolve()`（Windows `normcase`）。

## 7. 启动器 / 首次安装

- `.app`/`.exe`/可执行是 PyInstaller 小壳（不打包 torch）；`gui_app/launcher/setup_page.html`
  被放进 bundle；启动器找发布根目录（向上找 `gui_app/gui_server.py`）。
- 启动顺序：已运行 GUI → 直接打开；安装中 → 打开安装页；`.venv` 就绪 →
  启动 GUI；否则 → 安装页。
- 安装页用内置 `.tools/python` + `.tools/uv` 创建 `.venv` 并安装
  `requirements.txt`；PyPI 镜像可选；日志实时显示；失败可重试。
- 安装后 `on_ready` 启动 venv 的 `gui_app/gui_server.py --no-browser`，
  读 `runtime/launcher.json` + `/api/health` 后打开界面。
- `runtime/launcher.json` / `setup.json` 0600；GUI 退出时删除。
- 自检：`python3 gui_app/launcher/launcher.py --self-check --no-open`（CI 用于打包冒烟）。

## 8. 发布

```bash
# 本地 macOS（需要 PyInstaller；发布包会自动带内置 Python/uv）
python3 gui_app/tools/build_release.py --version 0.2.0
# 只验证目录组装
python3 gui_app/tools/build_release.py --skip-launcher --skip-tools --no-zip --out /tmp/rel
```

- `gui_app/tools/build_release.py`：
  - 生成 `.icns`（macOS sips/iconutil）或 `.ico`（Windows Pillow）；
  - PyInstaller 构建 `gui_app/launcher/launcher.spec`；
  - 复制原项目文件 + `gui_app/` + 使用说明/VERSION；
  - 复制/安装 `.tools/python` + `.tools/uv`；
  - 空 `input/output/中间文件/LRC成品库/promptbook`；
  - 打 zip。
- CI：`.github/workflows/tests.yml`（三平台单测）与 `release.yml`
  （tag 构建三平台 zip，附 SHA256SUMS 与发布说明）。
- 未签名：macOS Gatekeeper/Windows SmartScreen 提示写进 `使用说明.txt`；
  有证书时可在 release workflow 增加 codesign/notarize/signtool（未默认启用）。

## 9. 测试

```bash
.venv/bin/python -m unittest discover -s gui_app/tests -v
.venv/bin/python -m compileall -q gui_app
```

- 测试不装 torch、不下载模型、不使用真实 API Key；API 测试用本地 mock。
- 真实模型识别：`test_gguf_meta.test_real_local_models`（本机模型存在时跑）。
- 三平台 CI 只测逻辑与打包；真实 ASR/llama-server 需在对应实机验证。

## 10. 本地双击 / 图标

- **macOS 开发机**：本机已构建 `gui_app/音声字幕工房.app`（使用项目现有 `.venv`，双击即可）。
  想要不依赖 `.venv` 的发布版，用 `gui_app/tools/build_release.py`（会带上 `.tools` 和首次安装页）。
- **Windows `.exe`**：PyInstaller 不能从 macOS 交叉编译 Windows 程序。需要在 Windows 上
  `pip install pyinstaller` 后运行 `python3 gui_app/tools/build_release.py`，或推 tag 让
  `.github/workflows/release.yml` 在 `windows-latest` 上构建。
- **Linux 可执行**：同理，在 Linux 或 CI 上构建。
- **图标资源**：`gui_app/launcher/assets/icon.icns`（macOS）、`gui_app/launcher/assets/icon.ico`（Windows，多尺寸）、
  `gui_app/launcher/assets/icon.png`（Linux/预览）。PyInstaller spec 和 `build_release.py` 会自动使用。
- 根目录的 `.app` 已被 `.gitignore` 忽略，不会误提交构建产物。

## 11. 已知限制 / 后续

- 首次安装需要联网和 2–4GB 磁盘；暂不提供完全离线的一体化包。
- 本地模型仍需用户自备 `.gguf` 与 llama-server；云端 API 推荐给非技术用户。
- 默认未签名；安装器/自动更新/pywebview 原生窗口/离线依赖包为后续可选项。
- 一次一个任务/一个作品；不做队列。
- 移动发布文件夹后可执行“重新安装环境”；`.venv` 有绝对路径，升级建议复制数据到新文件夹。
